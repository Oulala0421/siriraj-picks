# Siriraj 套房挑選 ❤

手機就能用的「交友式」滑卡選房工具：精選 Siriraj 醫院周邊、月租 ≤ 6,000 THB、綜合品質分 ≥ 80 的 40 間套房。

- **← 淘汰　→ 選擇**，可一輪一輪篩到剩最愛的幾間，並匯出 CSV
- 每張卡：照片輪播、租金 / 坪數 / 距 Siriraj / 冷氣 / 電梯 / 空房 / 安全 / 區域、看物件 + Google 地圖連結
- 右上可切換 **中文 ⇄ ไทย**
- 照片直接讀各租屋站 CDN（不需自行存放），手機有網路即可瀏覽

純靜態單檔 `index.html`，Vercel 直接部署即可。資料為公開租屋平台（Renthub / Hipflat）之公開資訊，個人找房自用。
